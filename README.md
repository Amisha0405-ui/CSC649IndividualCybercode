# Cybercode: An Interactive Educational Game for Programming and Cybersecurity

> **Summary:** New programmers and self-learners face high frustration learning programming and poor practical cyber threat identification due to conventional way of learning; Cybercode solves this through an interactive web-based educational gamification platform.

## Problem Statement
Code, debug, and cyber threat spotting and learning can be an incredibly frustrating experience for computer science students and self-learners due to traditional computing classes relying heavily on static slides and passive lectures. Without active feedback loops or step-by-step guidance, beginners experience mental fatigue and high frustration, leaving them unprepared to identify live malicious code, phishing scripts, or social engineering tactics in real-world environments.
