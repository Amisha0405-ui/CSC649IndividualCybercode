# Cybercode: An Interactive Educational Game for Programming and Cybersecurity

> **Summary:** New programmers and self-learners face high frustration learning programming and poor practical cyber threat identification due to conventional way of learning; Cybercode solves this through an interactive web-based educational gamification platform.

## Problem Statement
Computer science students and self-learners often face severe frustration and mental fatigue when learning programming syntax, semantic logic, debugging and cyber threat identification. This issue occurs because traditional computing learning rely heavily on static lecture slides and passive reading rather than providing immediate, hands-on practice and real-time error validation. For example, beginner students frequently get stuck on simple syntax errors or fail to spot the wrong phishing link during lab hours, forcing them to wait for their lecturers response for hours or days even before progressing to the next step. Moreover, without feedback loops and step-by-step guidance, learners fail to develop practical operational skills, leaving them unprepared to handle live malicious code or social engineering tactics in real-world environments.
